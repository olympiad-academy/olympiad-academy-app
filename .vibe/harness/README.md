## Task / plan / build / ship handoff

- task: raw-intent → work-brief; native command /skill:task.
  - Persist: Persist .vibe/work/<work-id>/raw-intent.md when needed and .vibe/work/<work-id>/work-brief.json as the durable output.
  - Handoff: Hand exactly one Work Brief to plan; do not produce implementation-plan, build-result, or ship-packet in task.
- plan: work-brief → implementation-plan-with-verification-delta; native command /skill:plan.
  - Persist: Persist .vibe/work/<work-id>/implementation-plan.json; keep status draft until explicit operator approval.
  - Handoff: Hand an approved persisted plan to build; do not execute build or ship work from plan.
- build: approved-implementation-plan → build-result; native command /skill:build.
  - Persist: Persist .vibe/work/<work-id>/build-result.json with changed files, evidence refs, and any blockers.
  - Handoff: Hand the Build Result plus evidence to ship; do not claim release readiness without the persisted packet.
- ship: build-result → ship-packet; native command /skill:ship.
  - Persist: Persist .vibe/work/<work-id>/ship-packet.json with release notes, risks, and final evidence links.
  - Handoff: Stop if required evidence is missing; do not push, deploy, or open external PRs unless explicitly authorized outside create/import.
