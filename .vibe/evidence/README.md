# .vibe/evidence — verification and design evidence

Evidence artifacts per work item live under `.vibe/evidence/<work-id>/`.
Design snapshots live under `.vibe/evidence/<work-id>/design/`.

Note: `.vibe/evidence/**` is gitignored — evidence is local to the machine
(operator decision, 2026-08-06: sole frontend developer + design owner).
Rebuild design snapshots from their documented source (see each snapshot
README's Provenance section) when working from a fresh clone.

To capture a snapshot for a new task, follow the SOP in
`docs/design-snapshots.md`.
